# Manideep Sai’s pixel workspace

My personal portfolio is a pixel-art desk you can explore. Type `P` in the
monitor to open my projects, try the light sensor on the ThinkPad, or click
Byte, the cat on the windowsill.

## Editing the site

- `docs/portfolio.js` — my introduction, projects, links, and Byte’s dialogue
- `docs/lake.css` — room layout, monitor size, and desk spacing
- `docs/art.js` — pixel artwork
- `docs/app.js` — terminal commands and interactions

To preview a change, open `docs/index.html` in a browser.
